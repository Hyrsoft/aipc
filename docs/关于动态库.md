
需要动态链接一些rk的库：
```cmake
set(MPI_LIBS 
    sample_comm
    rockit
    rockchip_mpp
    rkaiq
    rga
    rtsp
    pthread
    dl
)
```
可以从`third_party/luckfox_pico_rkmpi_example/lib/uclibc`中获取

```bash
❯ ls

librga.a   librkaiq.so   librockchip_mpp.a   librockchip_mpp.so.1  librockit_full.so  librockit_tiny.so  librtsp.a
```

默认 libdatachannel 的动态库在编译产物中。构建目录可用 `AIPC_BUILD_DIR` 覆盖：

```bash
export AIPC_BUILD_DIR="${AIPC_BUILD_DIR:-build/Debug}"
ls "$AIPC_BUILD_DIR/libdatachannel"
CMakeFiles  cmake_install.cmake  deps  libdatachannel.so  libdatachannel.so.0.24  libdatachannel.so.0.24.0  libdatachannel-static.a
```

使用脚本把相关 `.so` 上传到开发板系统库目录。远端主机和目录可通过环境变量或参数覆盖：

```bash
export AIPC_REMOTE_HOST="${AIPC_REMOTE_HOST:-root@192.168.8.235}"
export AIPC_REMOTE_LIB_DIR="${AIPC_REMOTE_LIB_DIR:-/usr/lib}"
export AIPC_BUILD_DIR="${AIPC_BUILD_DIR:-build/Debug}"

./assets/install_dynamic_libs.sh "$AIPC_REMOTE_HOST" "$AIPC_REMOTE_LIB_DIR"
```
